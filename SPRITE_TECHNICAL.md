# Carcosa — sprite & palette technical notes

**Last updated:** 2026-08-16  
Living reference for swapping art without breaking rendering or collision. Named palettes live in two places and must stay in sync: `src/frontend/lib/palettes.ts` (runtime tile wash) and `src/frontend/public/assets/palettes.json` (art bible, regenerated by `dev_scripts/extract-palettes.py`).

---

## 1. Where files live

| What | Path |
|------|------|
| Runtime sprites | `src/frontend/public/assets/sprites/*.png` |
| Sprite id → size / collision / sheet | `src/frontend/public/assets/sprites/manifest.json` |
| Tileset atlases | `src/frontend/public/assets/tilesets/*.png` |
| Tile id → atlas cell | `src/frontend/public/assets/tilesets/manifest.json` |
| Human catalog (notes, facing, aliases) | `src/frontend/public/assets/catalog.json` |
| Named + sampled palettes | `src/frontend/public/assets/palettes.json` |
| Runtime palette wash | `src/frontend/lib/palettes.ts` |
| Overworld object placement | `src/backend/Gameplay/OverworldWorldGen.cs` |

Renderer reads **manifest.json keys**, not filenames. Several ids can share one PNG via `"file": "other.png"`.

After `npm run build`, the same tree is copied to `src/backend/wwwroot/assets/`.

## 2. Exact sprite sizes

Tiles are always **32×32**. Atlases are **8 columns**. Character sheets are **walk rows first, then attack rows**. Facing order for 4-dir sheets: **down, left, right, up**.

| `player_default`, `player_detective` | 32×32 | 4 | 4 | yes | aliases → `player_b.png` |
| `player_gangster` | 32×32 | 4 | 4 | yes | alias → `player_c.png` |

| `villager_*`, `satyr_*`, `npc_*` (most) | 32×32 | 4 | 4 | yes | see manifest |
| `cultist_*`, `cult_leader` | 32×32 | 4 | 4 | yes | dungeon + overworld |
| `gronk`, `elite_gronk` | **48×48** | 4 | 1 (south) | 2 | elite aliases `gronk.png` |
| `boss_warehouse` | **48×48** | 4 | 1 | yes | Drowned Dock / God Serpent stand-in |

Sheet math (4 dir × 4 walk + 4 dir × 2 attack):

- 32px cell → **128×256**
- 48px cell → **192×192** if 1 dir × (4 walk + 2 attack) stacked as two rows, or check the actual PNG

Always measure the PNG; `manifest.json` `width`/`height` is the **cell**, not the sheet.

## 4. `dev_scripts` — what to run

Run from the repo with Python + Pillow. Paths inside the scripts are absolute to this machine’s checkout; edit `OUT_*` if you clone elsewhere.

| Script | When to run | What it does |
|--------|-------------|--------------|
| `extract-palettes.py` | After any PNG add/replace | Rewrites `public/assets/palettes.json` (`named` + `sampled` per file) |
| `pack-sprite-assets.py` | New character/prop from the raw `assets` dump | Pixelates into 32px tilesets + entity sheets; walk rows then attack |
| `pack-attack-rows.py` | Sheet has walk but no attack | Appends lunge attack rows (2 frames) |
| `pack-biome-art.py` | Regenerating biome atlases from `raw_assets` | Slices concept JPGs → 32px tiles + slash placeholders |
| `pack-drowned-docks-art.py` | Drowned Dock tiles / Merek / Agwan / dream-ship | Packs dock tileset + those sprites |
| `pack-villager-sprites.py` | Village NPC portraits | Builds 128×256 D/L/R/U + attack sheets |

**Safe swap (no script):** drop a PNG next to the old one with the **same filename and cell size**, keep transparency, keep feet on the bottom row. Manifest `width`/`height` must match the cell.

**New id:** add PNG → add key in `sprites/manifest.json` (`collision`, `collisionRadius` in **tiles**, optional `"file"` to reuse a sheet) → add a row in `catalog.json` → place in `OverworldWorldGen` if it is a world object → rebuild frontend.

**Do not** change collision radius without walking the object in-game. Buildings use large radii (1.4–3.2 tiles); the husk is 0.25 so Merek remains talkable beside it.

## 5. Pipeline rules (do not break rendering)

1. **Feet on the bottom.** DrawY is feet-anchored. Extra empty pixels under the feet float the sprite; extra pixels above are fine.
2. **Walk rows, then attack rows.** `attackRows: true` in catalog / `attackFrames` in manifest. Attack duration ~280ms.
3. **Aliases via `file`.** Cosmetic classes (`player_detective`) must not duplicate PNGs.
4. **One cell size per sheet.** Mixing 32 and 48 on one PNG will slice wrong.
5. **Collision is tiles, not pixels.** `collisionRadius` is in map tiles (player radius 0.3).
6. **World object `type` string must equal the manifest key.** Quest pickup looks for `old_book_husk`.
7. **Rebuild frontend** (`npm run build` or full `dotnet build`) so `wwwroot` matches `public/assets`.
8. Magenta / hot pink is sampler trash, not a Carcosa color.
