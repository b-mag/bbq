# Dev scripts

| Folder | Use |
| --- | --- |
| `release/` | Native AOT publish + launchers. Run `release/build_all_release.bat` first. |
| `develop/` | Debug `dotnet build` + the same launchers pointed at Debug exes. Run `develop/build_all_debug.bat` first. |
| `python/` | Art pipeline (palettes, sprites, tilesets). Not used to launch the game. |
| `obsolete_or_fix/` | Old per-project build scripts. Do not use. |
